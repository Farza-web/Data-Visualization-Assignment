# Data Visualization Assignment

This repository contains a Python data visualization assignment using three popular datasets: **Titanic, Iris, and Tips**.

##  Datasets

* **Titanic Dataset** – Passenger information and survival data
* **Iris Dataset** – Flower measurements and species
* **Tips Dataset** – Restaurant bills, tips, and customer information

##  Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook / Kaggle Notebook

## Visualizations

### Univariate Analysis

* Pie Chart
* Count Plot
* KDE + Rug Plot
* Violin Plot
* Box Plot
* Boxen Plot
* Histogram

### Bivariate Analysis

* Scatter Plot
* Line Plot
* Joint Plot
* Hexbin Plot
* 2D KDE Plot
* Box Plot
* Violin Plot
* Swarm Plot
* Count Plot

### Multivariate Analysis

* Scatter Plot
* Pair Plot
* Heatmap
* FacetGrid Plot
* PairGrid
* Joint Plot
* Boxen Plot

##  Objective

The main objective of this assignment is to understand different types of data visualization techniques and apply them to real-world datasets.
